# Book Recommender System

This is a machine learning based book recommendation system project.

## Work Done
- Data cleaning
- Exploratory Data Analysis (EDA)
- Popular books analysis
- Ratings analysis
- Dataset merging using pandas

## Technologies Used
- Python
- Pandas
- NumPy
- Matplotlib
- Seaborn
- Jupyter Notebook

## Dataset Used
Book Recommendation Dataset  
Source : https://www.kaggle.com/datasets/arashnic/book-recommendation-dataset

The dataset contains:
- Books.csv
- Users.csv
- Ratings.csv
